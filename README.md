# 🥗 AR NutriQuest: ภารกิจพิชิตสารอาหาร ป.6 (เกม AR แบบสัมผัส)

สื่อการเรียนรู้เสมือนจริง (WebAR Interactive Touch Game) กลุ่มสาระการเรียนรู้วิทยาศาสตร์และเทคโนโลยี ชั้นประถมศึกษาปีที่ 6 ตามหลักสูตรแกนกลางการศึกษาขั้นพื้นฐาน (สสวท.)

---

## 🌟 จุดเด่นและระบบการเล่น (Features)

1. **ระบบควบคุม AR สองรูปแบบ (Dual Input Mode)**:
   - **AR Hand Tracking (กล้องตรวจจับมือ AI)**: ยกมือขึ้นหน้ากล้องเว็บแคม จีบนิ้ว/กำมือเพื่อแตะจับอาหาร 3D ในอากาศได้จริง
   - **Touch Screen & Mouse Mode**: แตะสัมผัสบนหน้าจอ iPad, แท็บเล็ต หรือคลิกลากวางด้วยเมาส์ได้ 100%

2. **5 โหมดการเรียนรู้ตรงตามตัวชี้วัด ป.6**:
   - 🎮 **โหมด 1: แยกสารอาหาร 6 หมู่ (Catch & Classify)** — โปรตีน, คาร์โบไฮเดรต, ไขมัน, วิตามิน, เกลือแร่, น้ำ พร้อมระบุพลังงาน (kcal) และประโยชน์
   - 🍱 **โหมด 2: เชฟจัดจานสุขภาพ (Healthy Plate & Calorie Matcher)** — จัดสัดส่วนอาหารตามธงโภชนาการ และพลังงานที่เหมาะสมตามวัย (500 - 600 kcal/มื้อ)
   - 🏥 **โหมด 3: หมอน้อยรักษาโรค (Nutrition Hospital Detective)** — วินิจฉัยอาการโรคขาดสารอาหาร (เหน็บชา, เลือดออกตามไรฟัน, ปากนกกระจอก, ตาบอดกลางคืน, คอพอก, กระดูกอ่อน) แล้วป้อนอาหารบำบัด
   - 🧪 **โหมด 4: ห้องทดลองเคมีอาหาร (Virtual Food Lab Simulator)** — หยดสารละลายไอโอดีนทดสอบแป้ง, ไบยูเรตทดสอบโปรตีน, กระดาษทดสอบไขมัน
   - 📝 **โหมด 5: แบบทดสอบวัดระดับ 10 ข้อ + เกียรติบัตร (Quiz & Certificate)** — มีเสียงอ่านโจทย์ภาษาไทย และสร้างไฟล์เกียรติบัตร (PNG) บันทึกชื่อนักเรียนได้จริง

3. **ระบบเสียงแบบไดนามิก**:
   - เสียงเอฟเฟกต์ (SFX) สังเคราะห์จาก Web Audio API
   - เสียงพากย์บรรยายภาษาไทย (Web Speech API)

## 🚀 วิธีการเปิดใช้งาน (How to Run)

### วิธีที่ 1: ดับเบิลคลิกไฟล์ Launcher (ง่ายที่สุดบน Windows)
1. ดับเบิลคลิกที่ไฟล์ `start_game.bat`
2. ระบบจะเปิดเซิร์ฟเวอร์และเปิดเว็บเบราว์เซอร์ให้อัตโนมัติที่ `http://localhost:8080/`

### วิธีที่ 2: รันผ่านคำสั่ง Node.js / NPM (ถ้ามี)
```bash
npm run dev
# หรือ
npx -y serve . -l 3000
```
